# Blade Gunner — Aetheria

Mobile fantasy RPG prototype (single-file HTML5).

**Play now:** https://phtbenny-afk.github.io/blade-gunner-aetheria/

**Current version: v10**

## What's new in v10
- Gear set bonuses (Wingstrider / Aetherbound / Voidtouched)
- Zone objectives under the wave badge
- Expanded gear pool + smarter set-aware drops
- Companion skill frequency polish

Full playable file lives in the project Google Drive folder "Blade Gunner - Aetheria Game". Open the latest `blade-gunner-v*-playable.html` directly in Safari on iPhone for the complete experience.
