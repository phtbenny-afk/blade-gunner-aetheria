# Blade Gunner — Aetheria

Mobile fantasy RPG prototype (single-file HTML5).

**Play now:** https://phtbenny-afk.github.io/blade-gunner-aetheria/

**Current version: v13**

## What's new in v13
- Enemy variety with behaviors: Armored (damage reduction + shield icon), Enrage (ATK boost at low HP + red pulse/ENRAGE badge), Healer (ally heal + green particles)
- New types: Iron Sentinel, Rage Fiend, Aether Mender
- Clearer status visuals and consistent armor reduction across abilities/companions
- Behavior bias after wave 4 for more interesting mid-game combat
- Prior: Quest Log (7 quests), gear sets, dual companions, AFK, talents, inventory, elites, vulnerability marks, combat juice

Full playable single-file HTML lives in Google Drive (source of truth). The GitHub Pages index hosts the latest build. Open the Drive `blade-gunner-v13-playable.html` directly in Safari on iPhone for the complete experience.
